# GitHub Repository Topics

The following topics should be added to this repository via GitHub's repository settings:

## Recommended Topics

- `erc-8040`
- `esg`
- `tokenization`
- `rust`
- `blockchain`
- `swift-iso20022`
- `iso20022`
- `compliance`
- `defi`

## How to Add Topics

1. Go to the repository page on GitHub
2. Click on the gear icon (⚙️) next to "About" on the right side
3. Add the topics listed above in the "Topics" field
4. Click "Save changes"

## Why These Topics Matter

These topics improve repository discoverability and help connect with:
- Developers working on ERC standards
- ESG and sustainability-focused projects
- Rust blockchain developers
- ISO 20022 and SWIFT integration projects
- DeFi and compliance infrastructure teams
